# Meditrack - Personal Health & Medication Tracker
**Meditrack** is a cross-platform mobile application built with **Flutter** and **Dart** designed to help users track their daily medications, health routines, and medical appointments effortlessly. Never miss a dose again!
## ✨ Features
- **Smart Medication Reminders:** Set custom schedules and get timely notifications for your daily medicines.
- **Pill Inventory Tracker:** Keep track of your remaining pills and receive low-stock alerts before you run out.
- **Health Logs:** Track vitals such as blood pressure, blood sugar, and weight over time.
- **Family Profiles:** Manage medications for children or elderly family members from a single app.
- **Doctor Appointments:** Schedule and get reminders for upcoming medical checkups.
- **Data Privacy:** Local storage option ensuring your personal health data stays secure.
## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **State Management:** Provider / Riverpod / BLoC
- **Local Database:** Hive / Sqflite
- **Backend / Cloud:** Firebase (Auth & Firestore)
- **Notifications:** `flutter_local_notifications`
