## About

MediTrack is a Flutter-based mobile application designed to help users manage their daily medication schedules and water intake. The app uses local SQLite storage for all data, ensuring user privacy.

## Features

- User registration and login with security question recovery
- Add, view, and delete medication reminders
- Daily water intake tracking with circular progress indicator
- Local push notifications for medication alarms
- Profile management

## How to Run

1. Make sure Flutter SDK is installed
2. Open a terminal in this directory
3. Run `flutter pub get` to install dependencies
4. Run `flutter run` to launch the app on a connected device or emulator

## Tech Stack

- Flutter & Dart
- SQLite (via sqflite package)
- flutter_local_notifications for reminders
- Material Design UI
